# Derlenmiş kitaplar

İki kitabı birlikte üretmek için `02-StatisticalTheoryTR` klasöründe:

```bash
make books
```

Yalnız Temel İstatistik kitabı için:

```bash
make temel
```

Yalnız İstatistik kitabı için:

```bash
make istatistik
```

Derlenmiş PDF dosyaları bu klasörde açık kitap adlarıyla oluşturulur.
